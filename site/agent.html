通用语言，本地 Agent 模拟。

Zio 的核心定位是一门通用编程语言——Agent 编排不是它的存在理由，而是它擅长的工作负载之一。 当前部署源是 Astro site/src/pages 与 site/content，此 HTML 为历史演示存档。 ZOS 与编译器工具链属于语言核心；CSP／JSON 是组合原语，不是完整模型、工具、会话、预算、取消 harness。WASM 不替代权限与隔离约束，也不保证跨环境逐位一致。 真实 WASM 求值不等于真实 LLM：本页响应与训练环境均为本地模拟。同像性支持代码表示／编辑，不意味着神经透明或正确性证明。

Planned：Grove 独立 APP 执行 Zio Agent 逻辑，真实 LLM 生成代码经解析、能力检查与隔离执行，以错误和执行证据修订；Web 展示源码、实际路径、diff，反馈生成逻辑候选，独立评估后人工批准正式版本。自动实验仅限批准预算与编辑范围，可信基线、鉴权、评估／检查点／发布守卫不可自改。ACP（Agent Client Protocol）先 client／teacher adapter、后 server；当前未实现。编译器自举不等于编辑器／APP 的 Zio 化。LLM 自述不是执行证据。

官方独立库目标均为 Planned：Grove 按需消费 Numa（数值连续数组、矩阵、向量与后端接口，不治理学习）、Rill（参数、子命令、帮助、命令组合、终端 IO、退出状态，不是语言求值器）、Loom（模型、工具、会话、预算、取消、provider、ACP，不治理业务学习、评估或发布）。三库独立版本，不是语言内建层或已可安装包；core 无反向依赖。Grove 负责实验、反馈、检查点、逻辑演化、评估、人工批准与产品 Web。当前 zio-ai 未改名，zio-cli 二进制不是 Rill 库。

CSP 通道 = Agent 消息总线

ZOS 对象系统 = Agent 建模

ZOS 的 Class／Generic Function／Method 子集可表达对象与能力分派；完整 MOP 为 Planned，不意味着 Agent harness 已实现。

🔀

JSON 原语 = LLM 结构化接口

json-parse / json-stringify 提供结构化数据读写；真实模型接入、响应验证与能力检查仍需 harness。同像性允许表示和编辑代码，不证明生成代码正确。

📦

WASM = 宿主执行边界

显式 EvalContext 支持状态隔离；JS FFI、资源预算和非确定性输入仍需宿主约束。
