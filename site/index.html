正交严密的核心设计定理

为长期演化与 Agent 编排设计的核心原则

⚡

1. 状态显式化

零 thread_local 全局变量。所有状态在显式 EvalContext 中，在 Rust/WASM/浏览器端隔离运行。

🦀

2. Rust 合同，Lisp 组合

Rust 提供底层 Native 契约与 WASM 零开销性能边界；Lisp 提供元编程与灵活组合层。

🌐

3. JS / Web 原体深度互操作

内置 js/eval、js/console-log、js/dom-set-text 等原语，直接在浏览器 WASM 环境操作 DOM 与 JS 全局上下文。

🧬

4. 宏扩充 Eval 语义

内置 syntax-rules 模式匹配与自动 gensym 命名空间，彻底消除变量捕获。

📦

5. 协议优于实现

基于 CLOS / AMOP 哲学的 ZOS 对象系统，Generic Function 支持基于 C3 线性化算法的多分派 (Multi-Dispatch)。

🔄

6. 统一并发与 CSP

内置 Future / Promise 异步延迟解算与 Go/Clojure 风格 CSP Channel（chan, send!, recv!）。

正交分层系统架构

从底层 Host 到扩展库生态与 WASM 嵌入层

应用程序与 Web 宿主层 (Application & WASM Layer)
site/index.html (Web REPL) • zio-cli (CLI & REPL) • [Planned: LSP Server / DAP Debugger]
扩展库生态层 (Extension Library Layer)
lib/zio/protocol.zio (Protocol 系统) • lib/zio/entity.zio (Entity 模型) • lib/zio/persistent.zio (持久化集合) • lib/zio/datalog.zio
标准库层 (Standard Library Layer)
core.zio (内嵌核心宏 defn, when, cond, ->, ->>, assoc, dissoc, get-in, assoc-in)
运行时 & ZOS 对象层 (Runtime & ZOS Layer)
AST Evaluator (TCO Trampoline) • ZOS Class/GF/Method/C3 • syntax-rules 卫生宏 • Future/Channel • JS FFI (js/eval, js/dom-set-text)
前端语法层 (Frontend Reader)
Tokenizer • Parser • Sexp AST (内嵌 Span 源码定位) • Reader Macro
Rust 宿主层 (Rust Host Layer)
EvalContext • EvalRuntime • ModuleRegistry • IoHost • NativeFn • wasm-bindgen
