A Modern General-Purpose Lisp.

Zio 是一门以同像性（Homoiconicity）为基石的现代通用脚本语言：一门语言覆盖从自动化脚本、服务编排到 Agent 应用的完整光谱。 当前由 Rust 实现并提供 WebAssembly，具备 CLOS/AMOP 方向的 ZOS 子集、syntax-rules 卫生子集与 JS / DOM 互操作；完整 MOP 为 Planned。 此 HTML 是历史演示存档，当前部署源为 site/src/pages 与 site/content（Astro）；历史数字不代表当前验收。当前 workspace 为 core / cli / ai / learning / app 五 crate。 ZOS object/class/GF/method/MOP 方向属于语言核心，完整 MOP 为 Planned。Planned：core 职责收敛，Zio 自举展开、分析与编译器，Rust 保留最小运行时、宿主和性能原语；自举不等于编辑器／APP 的 Zio 化。 Grove 是独立 APP，不是库优先产品壳。Planned：Grove 按需消费官方独立库 Numa、Rill、Loom，负责实验、反馈、检查点、逻辑演化、评估、人工批准与产品 Web；真实 LLM 生成代码，经解析、能力检查与隔离执行，以错误和证据修订。三库独立版本，不是语言内建层，core 无反向依赖；当前 zio-ai 未改名。 自动实验仅限批准预算与编辑范围，可信基线、鉴权、评估、检查点和发布守卫不可自改。ACP（Agent Client Protocol）先 client／teacher adapter、后 server，当前未实现。同像性支持代码表示／编辑，不证明神经透明或正确性；LLM 自述不是执行证据。

正交严密的核心设计定理

一门通用语言的设计原则——同样适用于脚本、服务与 Agent 编排

⚡

1. 状态显式化

零 thread_local 全局变量。所有状态在显式 EvalContext 中，在 Rust/WASM/浏览器端隔离运行。

🦀

2. Rust 边界，Zio 自举方向

当前运行时由 Rust 实现；目标由 Zio 编写展开、分析与编译器，Rust 保留最小运行时、宿主与性能原语。不宣称 WASM 或嵌入零开销。

🌐

3. JS / Web 原体深度互操作

内置 js/eval、js/console-log、js/dom-set-text 等原语，直接在浏览器 WASM 环境操作 DOM 与 JS 全局上下文。

🧬

4. 宏扩充 Eval 语义

内置 syntax-rules 模式匹配与 gensym，已有卫生子集测试；不宣称完整卫生性或消除所有变量捕获。

📦

5. 协议优于实现

基于 CLOS / AMOP 哲学的 ZOS 对象系统，Generic Function 支持基于 C3 线性化算法的多分派 (Multi-Dispatch)。

🔄

6. Future 与 Channel 原语

Current：Future 与 chan / send! / recv! 是同步求值与队列演示，不是异步调度器。完整异步与取消语义为 Planned。

正交分层系统架构

ZOS 与编译器工具链留在语言；Numa / Rill / Loom 独立库由 Grove 按需消费，目标均为 Planned

独立 Grove APP 与官方独立库 (Planned)
历史 HTML Web REPL；当前部署为 Astro site/src/pages。Planned：Grove 消费独立版本、按需引入的 Numa（数值连续数组/矩阵/向量与后端接口）、Rill（参数/子命令/帮助/命令组合/终端 IO/退出状态）、Loom（模型/工具/会话/预算/取消/provider/ACP）；不是语言内建层或已可安装包。Numa 不治理学习，Rill 不是语言求值器，Loom 不治理业务学习/评估/发布；Grove 负责这些业务边界。zio-cli 二进制不是 Rill 库
扩展库生态层 (Extension Library Layer)
lib/zio/protocol.zio (Protocol 系统) • lib/zio/entity.zio (Entity 模型) • lib/zio/persistent.zio (持久化集合) • lib/zio/datalog.zio
标准库层 (Standard Library Layer)
core.zio (内嵌核心宏 defn, when, cond, ->, ->>, assoc, dissoc, get-in, assoc-in)
运行时 & ZOS 对象层 (Runtime & ZOS Layer)
AST Evaluator • ZOS Class/GF/Method/C3 子集 • 宏卫生子集 • 同步 Future/Channel • JS FFI；完整 MOP 为 Planned
前端语法层 (Frontend Reader)
Tokenizer • Parser • Sexp AST (内嵌 Span 源码定位) • Reader Macro
Rust 宿主层 (Rust Host Layer)
EvalContext • EvalRuntime • ModuleRegistry • IoHost • NativeFn • wasm-bindgen
