正交严密的核心设计定理

为长期演化与 Agent 编排设计的五大核心原则

⚡

1. 状态显式化

零 thread_local 全局变量。所有运行时状态全在显式 EvalContext 中，天生具备多实例隔离与并发安全。

🦀

2. Rust 合同，Lisp 组合

Rust 提供底层 Native 契约与零开销性能边界；Lisp 提供元编程与灵活组合层。

🧬

3. 宏扩充 Eval 语义

宏是用户扩展语言特性的唯一标准方式。内置 syntax-rules 模式匹配与自动重命名gensym，彻底消除变量捕获。

🎯

4. 内核最小，其余是库

核心仅包含 Reader、Sexp AST 与 ZOS 基础。Datalog、Agent 编排与持久化集合均为扩展库。

📦

5. 协议优于实现

基于 CLOS / AMOP 哲学的 ZOS 对象系统，Generic Function 支持基于 C3 线性化算法的 3+ 参数多分派 (Multi-Dispatch)。

🔄

6. 统一并发与 CSP

内置 Future / Promise 异步延迟解算与 Go/Clojure 风格 CSP Channel（chan, send!, recv!）。

(defmacro swap! [a b]
  (syntax-rules ()
    ((swap! a b)
     (let [tmp a]
       (set! a b)
       (set! b tmp)))))
