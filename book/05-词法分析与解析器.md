# 05 - 词法分析与解析器：从文本到语法树

## 流程概览

从你按下回车到代码被执行，经过两步：

```
"(+ 1 2)"           ← 你输入的文本字符串
    │
    ▼
[ "(", "+", "1", "2", ")" ]  ← Lexer：词法分析，变成 Token 流
    │
    ▼
Sexp::List([Symbol("+"), Integer(1), Integer(2)])  ← Parser：解析成语法树
```

**Lexer（词法分析器）**：把字符流变成"词"（Token）。
**Parser（解析器）**：把 Token 流变成有结构的树（Sexp）。

## Lexer：从文本到 Token

打开 `core/src/reader/lexer.rs`。Lexer 虽然叫"词法分析器"，但实现很小巧——不到 100 行的 `tokenize` 函数：

### Token 是什么

```rust
pub struct Token {
    pub text: String,      // 词文本，比如 "(", "+", "42"
    pub start: BytePos,    // 在源码中的字节位置
}
```

Token 只是一个字符串 + 一个位置。没有类型标签——因为 Zio 的 tokenize 只在括号、引号、分号等"结构字符"处分隔，遇到空白就切。最终每个独立的词都是 Token。

### tokenize 核心逻辑

```rust
pub fn tokenize(input: &str) -> Vec<Token> {
    let mut tokens = Vec::new();
    let mut chars = input.char_indices().peekable();

    while let Some(&(pos, c)) = chars.peek() {
        match c {
            // 空白：空格、换行、制表符——跳过
            c if c.is_whitespace() => { chars.next(); }

            // 注释：以 ; 开头到行末
            ';' => skip_line_comment(&mut chars),

            // 结构字符：左右括号、方括号、花括号、引号
            '(' | ')' | '[' | ']' | '{' | '}' | '\'' | '`'
                => { tokens.push(Token::new(c.to_string(), BytePos(pos))); chars.next(); }

            // 字符串：以 " 开始
            '"' => read_string(&mut chars, &mut tokens, pos),

            // 其他：读取到一个完整词（遇到空白或结构字符为止）
            _ => read_word(&mut chars, &mut tokens, pos),
        }
    }
    tokens
}
```

### 动手看看

想象一下 `(+ 1 2)` 被 tokenize：

```
字符:  (   +   空格   1   空格   2   )
结果: ["(", "+", "1", "2", ")"]      ← 5 个 Token
```

注释和空白被忽略了。字符串被保留为带引号的完整 token。

## Parser：从 Token 到 Sexp

打开 `core/src/reader/reader.rs`。核心是 `read_from_tokens` 函数。

### 核心思路：栈

解析器维护一个栈。看到左括号 `(` → 入栈新列表；看到右括号 `)` → 弹出列表，作为元素加入父列表。

```
例子: (+ (* 2 3) 4)

处理 Token 的过程：

看到 (  →  入栈 []                  栈: [[]]
看到 +  →  加入当前列表              栈: [[+]]
看到 (  →  入栈 []                  栈: [[+] []]
看到 *  →  加入当前列表              栈: [[+] [*]]
看到 2  →  加入当前列表              栈: [[+] [* 2]]
看到 3  →  加入当前列表              栈: [[+] [* 2 3]]
看到 )  →  弹出 [* 2 3]             栈: [[+ [* 2 3]]]
            加入父列表
看到 4  →  加入当前列表              栈: [[+ [* 2 3] 4]]
看到 )  →  弹出最终列表              结果: (+ (* 2 3) 4)
```

### 解析原子

不是括号里面的词就是"原子"——数字、字符串、符号、关键字、布尔值等。

`parse_atom` 函数根据 token 文本判断类型：

```rust
fn parse_atom(token: &str, span: Option<Span>) -> Sexp {
    // 试着解析为整数
    if let Ok(n) = token.parse::<i64>() {
        return Sexp::Integer(n, span);
    }
    // 试着解析为浮点数
    if let Ok(f) = token.parse::<f64>() {
        return Sexp::Float(f, span);
    }
    // :keyword 以冒号开头
    if token.starts_with(':') {
        return Sexp::Keyword(token[1..].to_string(), span);
    }
    // "string" 以引号开头
    if token.starts_with('"') {
        return Sexp::String(unquote_string(token), span);
    }
    // true / false
    if token == "true" { return Sexp::Boolean(true, span); }
    if token == "false" { return Sexp::Boolean(false, span); }
    if token == "nil" { return Sexp::Nil; }
    // 数字开头但解析失败 → char 字面量
    if token.starts_with('\\') {
        return Sexp::Char(parse_char(token), span);
    }
    // 否则是符号
    Sexp::Symbol(token.to_string(), span)
}
```

### Reader Macro：' 的魔法

Lisp 中的 `'`（quote）是一个特殊的 reader macro：

```lisp
'x     →     (quote x)
'(1 2) →     (quote (1 2))
```

Parser 看到 `'` 时，会读取下一个表达式，然后把它包装成 `(quote <expr>)` 的形式：

```
输入:  '  (  1  2  3  )
处理:
  看到 ' → 读取下一个表达式 (1 2 3)
  返回 Sexp::List([Symbol("quote"), Sexp::List([1, 2, 3])])
```

这就是为什么 `'x` 等价于 `(quote x)`。

## 源代码位置：Span

解析器在创建每个 Sexp 节点时，会记录它的位置信息（通过 `make_span` 函数）：

```rust
fn make_span(source_id, start: BytePos, end: BytePos, input: &str) -> Span {
    // 根据字节偏移量计算行号和列号
    let line = ...;  // 计算 start 在第几行
    let col = ...;   // 计算 start 在第几列
    Span { source_id, start, end, line, col }
}
```

这样当程序出错时，Zio 可以说：

```
error: symbol not found: foobar
  ┌─ program.zio:3:5
  │
3 │   (foobar 42)
  │    ^^^^^^ symbol 'foobar' not found
```

## 完整读取流程

```rust
pub fn read(input: &str) -> Result<Sexp, ReaderError> {
    let tokens = tokenize(input);            // 1. 词法分析
    let mut tokens = tokens.into_iter().peekable();
    let (sexp, _) = read_from_tokens(&mut tokens, SourceId::NONE, input)?; // 2. 解析
    Ok(strip_spans(sexp))   // 3. 剥离 span（向后兼容）
}
```
