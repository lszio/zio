# 08 - 特殊形式详解：if、def、fn 的秘密

## 为什么需要"特殊形式"？

在 `eval_inner` 中，当我们看到一个列表 `(first args...)` 时，正常的流程是：
1. 求值 `first` 得到函数
2. 求值所有 `args` 得到参数
3. 调用函数

但有些"函数"不能这样处理——它们的参数需要特别对待。例如 `if`：

```lisp
(if true (println "yes") (println "no"))
```

如果先把所有参数求值——那 `(println "yes")` 和 `(println "no")` 都会执行。但 `if` 应该只执行一个分支！

这就是**特殊形式**存在的理由——它们不遵守"先求值参数再调用"的规则。

## 特殊形式的调度

`eval_special_form` 函数像一个总机：

```rust
pub fn eval_special_form(name, args, env, tail, engine) -> Result<Option<TailResult>, EvalError> {
    match name {
        "quote"   => Some(do_quote(args)),
        "def"     => Some(do_def(args, env, engine)?),
        "defn"    => Some(do_defn(args, env, engine)?),
        "defmacro"=> Some(do_defmacro(args, env, engine)?),
        "fn"      => Some(do_fn(args, env)?),
        "if"      => Some(do_if(args, env, tail, engine)?),
        "do"      => Some(do_do(args, env, tail, engine)?),
        "and"     => Some(do_and(args, env, tail, engine)?),
        "or"      => Some(do_or(args, env, tail, engine)?),
        "cond"    => Some(do_cond(args, env, tail, engine)?),
        "let"     => Some(do_let(args, env, tail, engine)?),
        "let*"    => Some(do_let_star(args, env, tail, engine)?),
        "loop"    => Some(do_loop(args, env, engine)?),
        "recur"   => Some(do_recur(args, env, tail, engine)?),
        "module"  => Some(do_module(args, env, engine)?),
        "require" => Some(do_require(args, env, engine)?),
        _         => None,  // 不是特殊形式 → 走正常 eval 流程
    }
}
```

如果返回 `Some(result)`，eval 直接使用这个结果。返回 `None` 就走正常流程。

## 深入几个关键特殊形式

### quote：最基本的特殊形式

```lisp
'x        → x       ;; 不查 x，返回符号 x
'(1 2 3)  → (1 2 3) ;; 不求值列表，返回列表本身
```

`quote` 的实现最简单——直接把参数作为 Sexp 返回，不做任何求值：

```rust
pub fn do_quote(args: &[Sexp]) -> Result<TailResult, EvalError> {
    if args.len() != 1 {
        return Err(EvalError::wrong_arg_count(1, args.len()));
    }
    // 关键：不求值 args[0]，直接作为数据返回
    Ok(TailResult::Value(sexp_to_value(&args[0])))
}
```

### if：条件分支

```lisp
(if condition
  then-branch     ;; 只当 condition 为真时求值
  else-branch)    ;; 只当 condition 为假时求值
```

**关键**：三个参数——条件、真分支、假分支——只有条件被求值，两个分支只选一个求值。

```rust
pub fn do_if(args, env, tail, engine) -> Result<TailResult, EvalError> {
    let condition = engine.eval_expr(&args[0], env, false)?;  // 只求值条件

    if is_truthy(condition.value()) {
        engine.eval_expr(&args[1], env, tail)   // 只求值 then 分支
    } else if args.len() >= 3 {
        engine.eval_expr(&args[2], env, tail)   // 只求值 else 分支
    } else {
        Ok(TailResult::Value(Value::Nil))        // 没有 else 分支 → nil
    }
}
```

注意：`tail` 参数被传递到分支求值中——如果 if 在尾位置，分支也在尾位置。

### def：定义全局变量

```lisp
(def pi 3.14)    ;; 定义 pi 为 3.14
```

**特殊之处**：它不求值名字参数，只求值值参数：

```rust
pub fn do_def(args, env, engine) -> Result<TailResult, EvalError> {
    let name = match &args[0] {
        Sexp::Symbol(s) => s.clone(),  // 名字不 eval—直接取字符串
        _ => return error,
    };
    let val = engine.eval_expr(&args[1], env, false)?;  // 值要 eval
    env.set(name, val.clone());        // 存入环境
    Ok(TailResult::Value(val))
}
```

### defn：定义函数

```lisp
(defn square [x]    ;; [x] 是参数列表
  (* x x))
```

**特殊之处**：不求值第二个参数（参数列表）和第三个参数（函数体），而是直接作为结构保存：

```rust
pub fn do_defn(args, env, engine) -> Result<TailResult, EvalError> {
    let name = match &args[0] { Sexp::Symbol(s) => s.clone(), ... };
    let (params, rest_param) = parse_params(&args[1])?;  // 参数列表→Vector<String>
    let body = args[2].clone();   // 函数体保持 Sexp，不求值

    let fn_val = Value::Function(Arc::new(Function {
        params,                          // 参数名
        body,                            // 函数体（Sexp）
        env: env.clone(),                // 捕获当前环境（闭包！）
    }));

    env.set(name, fn_val.clone());
    Ok(TailResult::Value(fn_val))
}
```

### let：词法绑定

```lisp
(let [x 10 y 20]   ;; 同时定义 x 和 y
  (+ x y))         ;; 在这些绑定下求值
```

`let` 的执行步骤：
1. 创建新环境（外层指向当前环境）
2. 对所有绑定对：求值初始化表达式，在新环境中设置值
3. 在所有绑定就绪的环境中求值 body

```rust
fn do_let_inner(args, env, tail, sequential, engine) {
    let bindings = parse_bindings(&args[0])?;  // [(name, init-expr), ...]
    let body_exprs = &args[1..];

    // 关键：创建子环境
    let new_env = Arc::new(Env::new(Some(env.clone())));

    for (name, init_expr) in &bindings {
        let val = engine.eval_expr(init_expr, &new_env, false)?;
        new_env.set(name.clone(), val.clone());  // 在子环境中设置
    }

    eval_last_body(body_exprs, &new_env, tail, engine)
}
```

## 什么是"尾位置"？

`if` 中，`tail` 参数是关键。当 Zio 处于尾位置时（比如函数体最后一句），`tail = true`，eval 知道可以不用建新帧。

以下都是尾位置：

```lisp
(defn foo [x]
  (bar x))           ;; ← bar 的调用是尾调用

(defn foo [x]
  (if (> x 0)
    (bar x)          ;; ← 尾位置
    (baz x)))        ;; ← 尾位置

(defn foo [x]
  (let [y (inc x)]
    (bar y)))        ;; ← 尾位置（let body 的最后）
```

## 动手实验

```lisp
;; 验证 if 的短路行为
(if true
  (println "THIS runs")
  (println "THIS does NOT run"))

;; def 在 if 内
(if true
  (def answer 42)
  (def answer 0))
answer   ;; → 42

;; let 嵌套
(let [x 5]
  (let [y (+ x 3)]
    (* x y)))       ;; → 40
```

## 核心记忆

> **特殊形式 = 不遵守"先求值参数"规则的 builtin。** 它直接操作参数的语法结构，决定哪些求值、哪些不求值、何时求值。

> `quote` 不求值任何东西。`if` 只选择性求值。`def` 不求值名字，只求值值。`let` 创建新环境用于绑定。
