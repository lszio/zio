# 09 - 内置函数体系：当 Lisp 遇见 Rust

## 什么是内置函数？

特殊形式是"改变求值规则的语法构造"，而**内置函数**（Built-in Functions）直接映射到 Rust 函数——它们走正常的 eval/apply 流程：参数先求值，然后调用 Rust 代码。

当前 Zio 有 **30 个内置函数**。打开 `core/src/builtins.rs` 可以看到全部。

## NativeFn 的 Rust 表示

```rust
pub struct NativeFn {
    pub name: &'static str,                        // 函数名，用于调试
    pub func: fn(Vector<Value>, &dyn EvalEngine) -> Result<Value, EvalError>,
}
```

每个 NativeFn 就是一个函数指针：接受 **Vector<Value>**（已求值的参数）和 **EvalEngine**（求值引擎），返回 Result<Value>。

## 内置函数分类

### 算术（+ - * /）

```lisp
(+ 1 2 3)       ;; → 6
(- 10 3)        ;; → 7
(* 2 3 4)       ;; → 24
(/ 10 2)        ;; → 5
(mod 10 3)      ;; → 1
```

看看 `+` 的实现：

```rust
pub fn add(args: Vector<Value>, _engine: &dyn EvalEngine) -> Result<Value, EvalError> {
    let mut sum = 0i64;
    for arg in &args {
        if let Value::Integer(n) = arg {
            sum += n;
        }
    }
    Ok(Value::Integer(sum))
}
```

简单直接：遍历参数，累加整数，返回结果。

### 比较（= < > <= >=）

```lisp
(= 3 3)         ;; → true
(< 2 5)         ;; → true
(>= 5 3)        ;; → true
```

### 类型谓词（nil? boolean? number? string? ...）

```lisp
(nil? nil)      ;; → true
(number? 42)    ;; → true
(string? "hi")  ;; → true
(symbol? 'foo)  ;; → true
(list? '(1 2))  ;; → true
(vector? [1 2]) ;; → true
(fn? +)         ;; → true（+ 是函数）
```

这些全部用一个辅助函数实现：

```rust
fn unary_pred(args: &Vector<Value>, pred: fn(&Value) -> bool) -> Result<Value, EvalError> {
    let val = &args[0];
    Ok(Value::Boolean(pred(val)))
}

pub fn is_nil(args, _engine) { unary_pred(args, |v| matches!(v, Value::Nil)) }
pub fn is_number(args, _engine) { unary_pred(args, |v| matches!(v, Value::Integer(_) | Value::Float(_))) }
// ...
```

### 列表操作（cons car cdr list）

Lisp 最基本的三种操作：

```lisp
(cons 1 '(2 3))    ;; → (1 2 3)   在列表头部添加元素
(car '(1 2 3))     ;; → 1         取第一个元素
(cdr '(1 2 3))     ;; → (2 3)     取除第一个外的剩余
(list 1 2 3)       ;; → (1 2 3)   用参数创建列表
```

### 高阶函数（map filter reduce apply）

```lisp
(map (fn [x] (* x 2)) '(1 2 3))        ;; → (2 4 6)
(filter (fn [x] (> x 2)) '(1 2 3 4))   ;; → (3 4)
(reduce + 0 '(1 2 3 4))                 ;; → 10
(apply + '(1 2 3))                      ;; → 6   列表展开为参数
```

看看 `map` 的实现——展示了高阶函数如何调用引擎：

```rust
pub fn map_fn(args: Vector<Value>, engine: &dyn EvalEngine) -> Result<Value, EvalError> {
    let func = &args[0];      // 第一个参数：函数
    let list = &args[1];      // 第二个参数：列表

    let mut result = Vector::new();
    if let Value::List(items) = list {
        for item in items {
            // 对每个元素调用函数
            let mapped = apply(func.clone(), vector![item.clone()], engine)?;
            result.push_back(mapped.into_value());
        }
    }
    Ok(Value::List(result))
}
```

注意 `engine` 参数——通过它调用 `apply` 来执行函数。这就是"Rust 是合同边界，Lisp 是组合层"的体现。

### 集合操作（get put count）

```lisp
(get {:a 1 :b 2} :a)      ;; → 1
(put {:a 1} :b 2)          ;; → {:a 1 :b 2}  返回新 map
(count [1 2 3])             ;; → 3
(count '(1 2))              ;; → 2
(range 5)                   ;; → [0 1 2 3 4]
(range 2 5)                 ;; → [2 3 4]
```

### 类型转换（str keyword symbol vector）

```lisp
(str "Hello " 42)          ;; → "Hello 42"
(keyword "foo")            ;; → :foo
(symbol "foo")             ;; → foo
(vector 1 2 3)             ;; → [1 2 3]
```

### I/O 和文件（println prn read-line load slurp spit）

```lisp
(println "Hello!")         ;; 打印并换行
(prn "no newline")         ;; 打印不换行
(load "program.zio")       ;; 从文件加载执行
(slurp "data.txt")         ;; 读取文件内容为字符串
(spit "out.txt" "data")    ;; 写入字符串到文件
```

### 字符串操作

```lisp
(str-join ", " ["a" "b" "c"])  ;; → "a, b, c"
(str-split "," "a,b,c")        ;; → ["a" "b" "c"]
(str-trim "  hello  ")         ;; → "hello"
(str-contains? "hello" "ell")  ;; → true
(str-starts-with? "hello" "he")  ;; → true
(str-ends-with? "hello" "lo")    ;; → true
```

### 宏展开（macroexpand macroexpand-1）

```lisp
(defmacro unless [test body]
  (list 'if test nil body))

(macroexpand-1 '(unless false 42))  ;; → (if false nil 42)
(macroexpand '(unless false 42))    ;; → (if false nil 42) 完整展开
(pprint '(if true (do 1 2 3)))      ;; 漂亮打印
```

### 反射（type class-of slot-value ...）

```lisp
(type 42)                   ;; → "Integer"
(type "hello")              ;; → "String"
```

## 安装到环境

所有这些函数在系统启动时通过 `setup_env` 注册：

```rust
pub fn setup_env(env: &Arc<Env>) {
    // 算术
    env.set("+".into(), Value::NativeFunction(NativeFn::new("+", add)));
    env.set("-".into(), Value::NativeFunction(NativeFn::new("-", sub)));
    env.set("*".into(), Value::NativeFunction(NativeFn::new("*", mul)));
    env.set("/".into(), Value::NativeFunction(NativeFn::new("/", div)));

    // 类型谓词
    env.set("nil?".into(), Value::NativeFunction(NativeFn::new("nil?", is_nil)));
    env.set("number?".into(), Value::NativeFunction(NativeFn::new("number?", is_number)));
    // ... 一共 30 个
}
```

## 动手实验

```lisp
;; 探索高阶函数
(def numbers [1 2 3 4 5])
(map (fn [x] (* x x)) numbers)

;; 字符串操作
(str-join " " (map (fn [s] (str s "!")) ["hello" "world"]))

;; 实用函数
(defn average [nums]
  (/ (reduce + 0 nums) (count nums)))

(average [10 20 30])     ;; → 20
```
