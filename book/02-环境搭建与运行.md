# 02 - 环境搭建：从安装到跑起来

> 2026-10-07 目录更新：本文教学代码与旧阶段/验收描述保留历史语境；源码链接和运行路径已映射到当前位置。现行目标是 `libs/` 的 Zio 库与 `apps/grove/` 的 Zio 业务迁移，Rust Grove 业务尚未整体重写；通用 Rust transport/host adapter 在 `contribs/native/loom/`。当前归属见[架构](../docs/zio-architecture.md)与[批准目录计划](../docs/superpowers/plans/2026-10-07-language-first-layout.md)。

## 你需要什么

| 工具 | 版本要求 | 用途 |
|------|---------|------|
| Rust | 1.75+ | 编译 Zio（安装见下） |
| Cargo | 随 Rust 自带 | 构建和测试 |
| Git | 任意 | 获取源码 |

## 第一步：安装 Rust

如果你还没有 Rust，打开终端运行：

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

跟着提示走（默认选项即可）。完成后重启终端或运行：

```bash
source $HOME/.cargo/env
```

验证安装：

```bash
rustc --version   # 应该显示 rustc 1.75.0 或更高
cargo --version   # 应该显示 cargo 1.75.0 或更高
```

## 第二步：获取 Zio 源码

```bash
git clone <项目仓库地址>
cd zio
```

项目结构如下（2026-10-07）：

```text
zio/
├── Cargo.toml
├── langs/
│   ├── core/                  # Rust 语言内核
│   └── cli/                   # 普通语言 CLI
├── libs/                      # Zio 标准库与领域库
├── contribs/native/loom/       # 通用 Rust transport/host adapter
├── apps/
│   ├── site/                  # 语言介绍、文档、WASM playground
│   └── grove/                 # 独立产品
│       ├── native/app/        # 现有 Rust 入口与业务
│       ├── native/learning/   # 现有 Rust 宿主与业务
│       └── workers/torch/     # CPU 后端
├── docs/
├── book/
├── blog/
└── tools/
```

结构迁移不等于 Grove Rust 业务已重写为 Zio；领域库与应用业务目标为 Zio，
必要原生合同仍在 contribs/宿主中。Rill、编译器自举、Tree-sitter、LSP
仍需后续实现与验收。当前目录合同见[架构](../docs/zio-architecture.md)。

## 第三步：编译并运行

```bash
cargo build
```

第一次编译会下载依赖（`im`、`thiserror`、`itertools`）并编译所有 Rust 代码。之后就是增量编译，快很多。

编译成功？运行 REPL：

```bash
cargo run -p zio-cli
```

你应该看到：

```
Zio REPL
Press Ctrl+D or type (exit) to quit
zio>
```

这就是 Zio 的交互式编程环境（REPL——Read-Eval-Print Loop）。

## 第四步：你的第一个 Zio 程序

在 `zio>` 提示符后逐行输入：

```lisp
(+ 1 2 3)
```

按回车，你应该看到：

```
6
```

再来：

```lisp
(println "Hello from Zio!")
```

```
Hello from Zio!
nil
```

`println` 输出内容并返回 `nil`。

定义你的第一个函数：

```lisp
(defn square [x] (* x x))

(square 5)
```

```
25
```

## 第五步：运行测试

确保一切正常：

```bash
cargo test
```

你应该看到 103+ 个测试全部通过。

## 第六步：别怕，拆开看看

用编辑器打开 `langs/core/src/` 下的文件。现在不用理解全部——只要看结构：

- `lib.rs` —— 模块声明，项目的地图
- `sexp.rs` —— 语法树定义
- `value.rs` —— 运行时值定义
- `eval.rs` —— 核心求值器
- `builtins/` —— 内建函数集（按域分模块）

每个文件都很小（200～600 行），可以一口气读完。

## 常见问题

### Q: `cargo build` 很慢？

第一次编译需要下载和编译依赖。后续只需 **cargo build** 增量编译。

### Q: 看不到 REPL？

试试 `cargo run -p zio-cli --release`。或者直接用编译好的二进制：

```bash
cargo build --release
./target/release/zio-cli
```

### Q: 想用 VS Code / Vim / Emacs 编辑？

都行。Zio 源码是 Rust 文件，Rust 的 LSP（rust-analyzer）支持很好。如果你用 VS Code，安装 rust-analyzer 插件即可获得代码补全和文档提示。

## 动手实验

1. 输入 `(if true "yes" "no")` 看看输出
2. 输入 `(def x 42)` 然后 `x` 查看结果
3. 试一个多行表达式：Zio REPL 支持跨行输入，括号没闭合时会等待
