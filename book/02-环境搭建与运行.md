# 02 - 环境搭建：从安装到跑起来

## 你需要什么

| 工具 | 版本要求 | 用途 |
|------|---------|------|
| Rust | 1.75+ | 编译 Zio（安装见下） |
| Cargo | 随 Rust 自带 | 构建和测试 |
| Git | 任意 | 获取源码 |

## 第一步：安装 Rust

如果你还没有 Rust，打开终端运行：

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

跟着提示走（默认选项即可）。完成后重启终端或运行：

```bash
source $HOME/.cargo/env
```

验证安装：

```bash
rustc --version   # 应该显示 rustc 1.75.0 或更高
cargo --version   # 应该显示 cargo 1.75.0 或更高
```

## 第二步：获取 Zio 源码

```bash
git clone <项目仓库地址>
cd zio
```

项目结构如下：

```
zio/
├── Cargo.toml       # 工作区根配置
├── core/            # 核心库（zio-core crate）
│   ├── Cargo.toml
│   ├── src/         # 所有核心源码
│   └── benches/     # 性能测试
├── cli/             # 命令行工具（zio CLI crate）
│   ├── Cargo.toml
│   └── src/main.rs  # REPL 入口
├── docs/            # 文档
├── blog/            # 系列博文
├── lib/             # Zio 标准库 (.zio 源码文件)
└── tools/           # 辅助工具
```

## 第三步：编译并运行

```bash
cargo build
```

第一次编译会下载依赖（`im`、`thiserror`、`itertools`）并编译所有 Rust 代码。之后就是增量编译，快很多。

编译成功？运行 REPL：

```bash
cargo run
```

你应该看到：

```
Zio REPL
Press Ctrl+D or type (exit) to quit
zio>
```

这就是 Zio 的交互式编程环境（REPL——Read-Eval-Print Loop）。

## 第四步：你的第一个 Zio 程序

在 `zio>` 提示符后逐行输入：

```lisp
(+ 1 2 3)
```

按回车，你应该看到：

```
6
```

再来：

```lisp
(println "Hello from Zio!")
```

```
Hello from Zio!
nil
```

`println` 输出内容并返回 `nil`。

定义你的第一个函数：

```lisp
(defn square [x] (* x x))

(square 5)
```

```
25
```

## 第五步：运行测试

确保一切正常：

```bash
cargo test
```

你应该看到 103+ 个测试全部通过。

## 第六步：别怕，拆开看看

用编辑器打开 `core/src/` 下的文件。现在不用理解全部——只要看结构：

- `lib.rs` —— 模块声明，项目的地图
- `sexp.rs` —— 语法树定义
- `value.rs` —— 运行时值定义
- `eval.rs` —— 核心求值器
- `builtins.rs` —— 内建函数集

每个文件都很小（200～600 行），可以一口气读完。

## 常见问题

### Q: `cargo build` 很慢？

第一次编译需要下载和编译依赖。后续只需 **cargo build** 增量编译。

### Q: 看不到 REPL？

试试 `cargo run --release`。或者直接用编译好的二进制：

```bash
cargo build --release
./target/release/zio-cli
```

### Q: 想用 VS Code / Vim / Emacs 编辑？

都行。Zio 源码是 Rust 文件，Rust 的 LSP（rust-analyzer）支持很好。如果你用 VS Code，安装 rust-analyzer 插件即可获得代码补全和文档提示。

## 动手实验

1. 输入 `(if true "yes" "no")` 看看输出
2. 输入 `(def x 42)` 然后 `x` 查看结果
3. 试一个多行表达式：Zio REPL 支持跨行输入，括号没闭合时会等待

## 小结

```
安装 Rust  →  获取源码  →  cargo run  →  看到 REPL  →  开干！
```

你现在有了一个完整的 Zio 开发环境。下一章开始学 Lisp 语言本身。
