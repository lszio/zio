# Zio 语言从零入门教程

> 面向编程新手，从零开始理解 Zio：一门用 Rust 实现的现代 Lisp 语言。

## 致读者

本教程假设你：
- 有一点编程基础（学过任何一门语言的基本概念）
- **不要求** Rust 或 Lisp 经验
- 有好奇心，不怕读代码

每一章都是**可运行的**。我们会在每个阶段停下来运行代码、观察结果。

## 课程地图

```
第一部分：预备知识
  01. ─ Zio 是什么？── 项目概览与设计哲学
  02. ─ 环境搭建 ── 从安装到跑起来

第二部分：Lisp 语言
  03. ─ Lisp 入门 ── S 表达式、求值、函数
  04. ─ Sexp 与 Value ── 代码域和运行时域

第三部分：实现原理
  05. ─ 词法分析与解析器 ── 从文本到语法树
  06. ─ Eval 循环与 Apply ── 解释器的灵魂
  07. ─ 环境链与作用域 ── 变量去哪里了
  08. ─ 特殊形式详解 ── if、def、fn 的秘密
  09. ─ 内置函数体系 ── 当 Lisp 遇见 Rust

第四部分：高级特性
  10. ─ 宏系统 ── 写代码的代码
  11. ─ ZOS 对象系统 ── 运行时对象模型
  12. ─ 模块系统与包管理 ── 组织代码
  13. ─ REPL 与 CLI ── 交互式编程环境

第五部分：工程实践
  14. ─ 测试与基准 ── 如何保证正确性
  15. ─ 架构决策 ── 为什么这样设计
```

## 如何阅读

每章结构相同：

```
[[概念讲解]]  →  [[看见代码]]  →  [[动手实验]]  →  [[回顾思考]]
```

- **概念讲解**：用最朴素的语言说明「这是什么」
- **看见代码**：打开项目中的对应文件，讲解关键代码段
- **动手实验**：运行示例，修改参数，观察输出变化
- **回顾思考**：总结和延伸问题

## 开始

```bash
cd zio
cargo run
```

看到 REPL 提示符 `zio>`，输入你的第一个 Zio 表达式：

```lisp
(+ 1 2 3)
```

恭喜——你已经运行了 Zio！
