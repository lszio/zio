# 07 - 环境链与作用域：变量去哪里了

## 问题

当你写 `(def x 42)` 然后写 `x`，eval 怎么知道 `x` 的值是 42？

答案：**环境（Env）**。环境是一个"名字 → 值"的字典。

## Env：最简单的数据结构

打开 `core/src/env.rs`：

```rust
pub struct Env {
    data: RefCell<HashMap<String, Value>>,  // 名字 → 值的映射
    outer: Option<Arc<Env>>,                // 外层环境（父环境）
}
```

就这么简单。一个 HashMap 存变量，一个 outer 指针指向上层环境。

## 环境链

Zio 的变量查找遵循**词法作用域**（lexical scoping）——也叫静态作用域。变量的值由代码中**写在哪里**决定，而不是运行时调用栈。

```lisp
(def x 42)               ;; 顶层环境: {x: 42}

(defn outer []            ;; outer 定义在顶层
  (let [y 10]            ;; 新环境: {y: 10}，outer指向顶层
    (defn inner []       ;; inner 定义在 let 内部
      (let [z 5]         ;; 新环境: {z: 5}，inner指向 let 环境
        (+ x y z)))))    ;; 查找顺序: z → y → x（沿着链向上）
```

查找过程：

```
inner 内部: (+ x y z)
             │
        查找 z → 当前环境: 找到 5
             │
        查找 y → 当前环境: 没有 → 跳到外层（let 环境）: 找到 10
             │
        查找 x → 当前环境: 没有 → 跳到外层 → 跳到顶层（def 环境）: 找到 42
             │
            结果: 42 + 10 + 5 = 57
```

## 代码实现

### get：沿着链向上查找

```rust
impl Env {
    pub fn get(&self, key: &str) -> Option<Value> {
        // 1. 先查自己的 hashmap
        if let Some(val) = self.data.borrow().get(key) {
            return Some(val.clone());
        }
        // 2. 自己没找到，递归查外层
        if let Some(outer) = &self.outer {
            return outer.get(key);
        }
        // 3. 没有外层了 → 未定义
        None
    }
}
```

### set：只修改当前环境

```rust
impl Env {
    pub fn set(&self, key: String, value: Value) {
        self.data.borrow_mut().insert(key, value);  // 只改自己的 hashmap
    }
}
```

注意：`set` 不沿着链向上找——它只修改当前环境。所以 `def` 创建的是新绑定，不是修改外层的变量。

### bind：函数调用时创建新环境

```rust
pub fn bind(
    outer: &Arc<Env>,
    params: &Vector<String>,     // 参数名列表，如 ["a", "b"]
    args: &Vector<Value>,        // 参数值列表，如 [1, 2]
) -> Result<Arc<Env>, EvalError> {
    let env = Env::new(Some(outer.clone()));  // 创建子环境，outer指向调用环境
    for (param, arg) in params.iter().zip(args.iter()) {
        env.set(param.clone(), arg.clone());   // 参数名 → 参数值
    }
    Ok(Arc::new(env))
}
```

## 闭包：函数带着它的环境

看这段代码：

```lisp
(defn make-adder [x]
  (fn [y] (+ x y)))

(def add5 (make-adder 5))
(add5 3)    ;; → 8
```

`make-adder` 调用时创建了环境 `{x: 5}`，返回的匿名函数 `(fn [y] (+ x y))` **记住了这个环境**。

当 `add5` 被调用时：
1. 创建新环境 `{y: 3}`，外层指向 `{x: 5}` 的环境
2. 求值 `(+ x y)`：`x` 从外层环境找到 5，`y` 从当前环境找到 3
3. 结果 = 8

这个"函数 + 环境"的组合就是**闭包**。在 Zio 中，`Value::Function` 的定义：

```rust
pub struct Function {
    pub params: Vector<String>,     // 参数名
    pub body: Sexp,                 // 函数体
    pub env: Arc<Env>,              // 定义时捕获的环境 ← 这是闭包的关键
}
```

`env` 字段就是闭包的"记忆"。

## 作用域类型对比

| 类型 | 创建方式 | 生命周期 | 用途 |
|------|---------|---------|------|
| 全局环境 | 程序启动时创建 | 程序运行全程 | `def` 定义的变量 |
| 局部环境 | `let`/`let*` | let 块内 | 临时绑定 |
| 函数环境 | `fn`/`defn` 调用 | 函数调用期间 | 参数绑定 |
| 闭包环境 | 函数定义时捕获 | 函数对象存活期间 | "记住"外部变量 |

## 可视化：环境链

```
顶层 (global env):
  ┌──────────────┐
  │ x → 42       │
  │ add5 → func  │───────┐
  └──────────────┘       │
                          │ (闭包捕获的环境)
(let [y 10] ...)          │
  ┌──────────────┐        │
  │ y → 10       │        │
  │ inner → func │  outer→│  {x: 42}
  └──────────────┘        │
       │ outer            │
       ▼                  │
  ┌──────────────┐        │
  │ z → 5        │        │
  │ outer ───────┘        │
  └──────────────┘        │
                          │
(fn [y] (+ x y))          │
  ┌──────────────┐        │
  │ params: [y]  │        │
  │ env: ────────┘        │
  │ body: (+ x y)         │
  └──────────────┘
```

## 动手实验

```lisp
;; 词法作用域演示
(def x "global")
(let [x "local"]
  (println x)     ;; → "local"
  (let [x "inner"]
    (println x))) ;; → "inner"
(println x)       ;; → "global"   外层没被改

;; 闭包演示
(defn counter [init]
  (let [n init]
    (fn [] (set! n (+ n 1)) n)))  ;; 如果有了 set!

;; 多个环境独立
(defn greet [greeting]
  (fn [name] (println greeting name)))

(def hello (greet "Hello"))
(def hi (greet "Hi"))

(hello "Alice")  ;; → "Hello Alice"
(hi "Alice")     ;; → "Hi Alice"
```

## 核心记忆

> **环境 = HashMap + 外层指针。** 变量查找沿链向上，定义变量只改当前层。闭包 = 函数 + 定义时的环境。
