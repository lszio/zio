## 一句话定位

`Grove` 的目标是 **基于 Zio 的独立 APP**：第一产品主线是可执行 Zio Agent 逻辑、真实 LLM 生成代码、可见执行证据和受控修订，不以学习宿主库或产品壳作为产品边界。这个 Zio 应用目标尚未完成，不能把当前 Rust 应用称为已经由 Zio 实现。

当前 `apps/grove/main.zio` 是实际 Zio 应用入口，通过有根的 `require` 组合 `libs/loom/agent.zio` 通用循环，并读取宿主的 `:max_turns` 授权；库不再定义 Grove 的入口或默认轮数。存储、调度、评价、CLI/HTTP 等 Rust 业务仍在 `apps/grove/native/learning`（crate `grove`）与 `apps/grove/native/app`（crate `grove-app`，二进制 `grove`）；`apps/grove/workers/torch` 提供 CPU 后端。通用 Rust 模型适配在 `contribs/native/loom`（crate `loom`），不是 Zio 库的替代实现。Grove 尚未整体迁为 Zio，Rill 尚未实现。

候选筛选已进一步迁到 `apps/grove/selection.zio`：由 Zio 决定 accuracy 指标与质量／成本比较，先排除未通过硬门槛的候选；CLI 和 HTTP 共用 native 数据适配器，不再保留 Rust 筛选算法。策略构建时嵌入，尚不能热替换；当前成本仍统一为 1，同质同价互相排除的旧比较口径不变。筛选只是建议，评估记录与人工发布守卫仍在 native。

ZOS 的 object/class/GF/method/MOP 方向属于语言核心，不从 core 移出；完整 MOP 为 **Planned**。**Planned**：核心职责收敛，展开、分析与编译器由 Zio 自举；Rust 保留最小运行时、宿主与性能原语。编译器自举不等于用 Zio 编写编辑器或 APP。

## 第一产品验收主线（Planned）

可执行 Zio Agent 逻辑 → 真实 LLM 生成代码 → 解析、能力检查、隔离执行 → 错误与执行证据驱动修订 → Web 展示源码、实际执行路径与 diff → 用户反馈产生逻辑候选 → 独立评估 → 人工批准后成为正式版本。

自动实验、训练与检查点只可在已批准预算和编辑范围内进行。ZOS／编译器可信基线、鉴权、评估器、检查点与发布守卫不可被候选自改。Loom 的 ACP 指 **Agent Client Protocol**：双向目标，先实现 client 与 teacher adapter，server 后置；当前尚未实现。

## 为什么它长在 Zio 上，而不是旁边

| 能力 | Zio 提供的原语 |
| --- | --- |
| 模型即数据 | 同像性使程序可表示、检查与编辑；不意味着神经模型透明或程序正确性证明 |
| 学习策略 | `libs/learning/` 保留候选搜索、配方、群体选择、能力抽象的实验表示 |
| 反馈生命周期 | 当前有版本化记录与内容寻址制品；反馈到可执行逻辑修订闭环为 Planned |
| 消息传递 | 当前 `future-call` 同步求值，Channel 是同步队列占位能力，不证明并发；完整 Loom harness 仍未完成 |

**Zio 库目标与当前代码必须区分**：`libs/numa` 与 `libs/loom` 有现有 Zio 代码，但不证明完整数值后端或模型／工具／会话／预算／取消／ACP 已交付。Rust 宿主基础设施保留在 `contribs`，不是独立 Rust 库架构的换名。Rill 没有实现；以下是目标职责，不是已可安装的包。

| 边界 | 职责 |
| --- | --- |
| Numa | 数值计算、类型化连续数组、矩阵、向量与后端接口；不负责学习治理 |
| Rill | 参数、子命令、帮助、命令组合、终端 IO 与退出状态；不是语言求值器 |
| Loom | 模型、工具、会话、预算、取消、provider 与 ACP；不负责业务学习目标、评估或发布 |
| Grove | 独立 APP：实验、反馈、检查点、逻辑演化、独立评估、人工批准与产品 Web |

ZOS 与展开／分析／编译器工具链仍属 Zio 语言；core 不反向依赖上述库或 Grove。LLM 自述不作为执行证据。

## 拒绝优先的产品原则

grove 的多数代码在**拒绝**而不是在**接受**：

- **Planned**：可部署快照必须具备可验证执行图与依赖，防止 reader 为已提交权重随意补图；当前 joint 快照缺图尚待修复，`modules` / `ensemble` / `graph` 是可选字段，不宣称三字段强制存在已被执行。
- 组合检查是**语义**的，不是数值的：同维不同语义空间被拒。
- `all-agree` 缺一个专家即 abstain——无法建立一致性时不假装一致。
- 异构输出空间的专家在 bind 阶段被拒，绝不平均。
- 未声明的信号类型、超上限预算、未知 recipe 一律拒绝。
- 未声明保留期的可达性分析**不删除任何东西**：未声明策略不是销毁历史的许可。

**Planned**：完整 Numa 数值后端与 Loom harness、Rill、Grove Zio 应用、上述第一产品验收主线、真实训练调度与受控发布。商业上游模型授权、真实业务数据／门槛、GPU 成本仍需独立验证。
