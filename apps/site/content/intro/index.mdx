## 从一个表达式开始

Zio 属于 Lisp 家族，是一门语义独立的通用编程语言；Rust 提供引导实现与必要运行时机制，不决定你必须用什么语言表达业务。你可以用 Zio 计算、处理数据、编写脚本，也可以把反复出现的业务规则组织成函数与库。括号不是额外的装饰：`(函数 参数...)` 就是最基本的组合方式，内层表达式的结果成为外层表达式的输入。

```lisp
(defn square [x] (* x x))
(+ (square 3) (square 4)) ;; => 25
```

不必先搭建项目。打开 [Playground](/playground/)，修改数字、增加表达式，马上观察结果；再沿着[语法入门](/syntax/)学习绑定、函数与条件。

## 用数据与函数描述问题

列表、向量、映射和集合让你直接表达一组值、一条记录或一组成员。关键字如 `:name` 常用作记录的字段名。函数也是值：可以传给另一个函数、从函数返回，或者捕获局部绑定形成闭包。

```lisp
(def readings [18 21 24 19])
(def warm (filter (fn [n] (> n 20)) readings))
(reduce + 0 warm) ;; => 45

(def profile {:name "Lin" :language "Zio"})
(get profile :name) ;; => "Lin"
```

把集合交给 `map`、`filter`、`reduce`，让每一步都对应一个清楚的变换。常用函数和领域能力可以从[库介绍](/libraries/)找到，再进入对应的[源码参考](/reference/)查看参数、语义和示例。

## 代码也是数据，宏扩展表达方式

引用的列表不会当作调用执行，而是一个可操作的数据值。宏接收尚未求值的代码，返回新的代码，让重复的控制结构可以拥有自己的名字。

```lisp
(defmacro unless [test body]
  (list 'if test nil body))

(unless false 42) ;; => 42
(macroexpand-1 '(unless false 42)) ;; => (if false nil 42)
```

先用普通函数组织计算，再在确实需要改变求值方式时使用宏。Zio 提供 `defmacro`、准引用与 `syntax-rules` 卫生子集；不要把它们理解成完整宏卫生性的保证。

## 对象与多分派

当数据具有稳定的结构，可以定义类、创建实例，并用通用函数描述操作。方法根据参数的类选择，而不只依附于某一个接收者；这让同一个操作能够针对不同类型提供不同实现。

```lisp
(defclass point nil
  ((x :initarg :x)
   (y :initarg :y)))
(def p (make-instance point :x 10 :y 20))
(defgeneric describe (shape))
(defmethod describe ((shape point))
  (str "Point(" (slot-value shape :x) ", " (slot-value shape :y) ")"))
(describe p) ;; => "Point(10, 20)"
```

现有 ZOS 支持类、实例、通用函数与多分派子集。更完整的对象模型协议并非当前保证；[ZOS 规范](/docs/zos-spec/)同时包含设计目标，阅读时需区分规范与已有能力。

## 在浏览器试写，在原生环境运行

浏览器 Playground 使用真实 WASM 求值器，会话保留定义，输出最后一个表达式的值或错误。适合学习表达式、实验函数和检查数据变换。原生 CLI 提供 REPL、脚本加载与模块使用；文件、网络等能力取决于运行环境和宿主授权，不能由浏览器实验推断。

**只执行你信任的代码。** WASM 中的 `js/eval` 与 DOM 原语可以访问当前页面。Playground 不提供超时、进程隔离或任意代码的安全保证；它不是运行不可信代码的沙箱。`future-call` 当前同步求值并包装结果，`chan / send! / recv!` 是同步队列，不能据此推断并发调度、阻塞或取消能力。

## 从语言到完整工具链

两条目标主线是：用 Zio 编写元循环求值器与自举编译器；保存、恢复运行时镜像并导出应用 bin/WASM。已交付与规划分开看待：

**已交付（实验面，命令可直接试用）**

- **自举编译器**：完整 Zio 前端在全新上下文编译自身，Stage 1/2/3 制品逐字节相同，Rust 引导与 VM 保留。`zio self-build --verify` 可复现。
- **运行时镜像**：保存／检查静态对象图，在新进程恢复环境与闭包，恢复后权限重新授予；不是暂停中的执行栈。入口为 `zio image save/inspect/run`。
- **独立应用导出**：`zio build INPUT --target native|browser|wasm-wasi -o APP` 支持三个目标；原生产物带 runtime 与 payload，浏览器 HTML 仍需同版本 JS/WASM 资源，不是离线自包含页面。
- **原生内嵌 JS**：`zio-js` 绑定 QuickJS，CLI 会话内以 `js/*` 提供。
- 其他已发行命令：`zio compile`、`zio fmt`、`zio lsp`。

**保留目标（规划）**

- `inline`／raw 块、Rust 引擎与 JIT。
- 跨宿主编译执行面一致性：浏览器端 `js/…` 点号解析仍仅支持解释执行；编译路径、数值／错误与权限合同仍需逐项对照。
- 单一安装、一次配齐解释器／编译器／LSP／语法资源／WASM／文档的完整开发发行包；当前原生包与浏览器引擎分开构建，浏览器 WASM 与 WASI 分别验收。

镜像须保留共享对象、循环与闭包，外部资源需显式重建否则拒绝保存；应用 bin 首轮是 bytecode + runtime 而非机器码 AOT，且不携带 LSP。外部解释型与编译型语言计划通过引擎库接入；`inline` 是外语代码入口，不等于必然 `eval`，也不是任意 Rust 源码直接求值。原生发行仅覆盖 Linux x86_64 与 aarch64。

以上是现状与目标边界，不代表所有规划均已落地；现有能力以[特性矩阵](/docs/feature-matrix/)为准，详见[语言与工具链设计](/docs/superpowers/specs/2026-10-11-zio-language-toolchain-design/)与[执行计划](/docs/superpowers/plans/2026-10-11-zio-language-toolchain/)。

## 安装 0.2.2 alpha 预览

0.2.2 是语言与工具链的 alpha 预览：GitHub Release 为 prerelease，npm 以 `alpha` 标签发布，稳定的 `latest` 标签不受影响。原生发行仅 Linux x86_64 与 aarch64。

```bash
npm install -g @lszio/zio@alpha
zio           # 首次运行按版本下载匹配的平台归档
zio app.zio   # 运行脚本
```

也可以直接下载 [GitHub Release v0.2.2](https://github.com/lszio/zio/releases/tag/v0.2.2) 的 Linux 归档，或使用精确版本镜像 `ghcr.io/lszio/zio:0.2.2`。
