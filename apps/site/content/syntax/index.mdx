## 怎样学习这一页

按“表达式与数据 → 定义与函数 → 条件与顺序求值”的顺序，把代码逐段复制到 [Playground](/playground/)。每次只改一个值或一个表达式，比较输出。初次接触 Lisp 可以先读[语言介绍](/intro/)；找函数用法请看[库介绍](/libraries/)与[库参考](/reference/)。

本页是入门摘要；当前作用域、求值次序和宿主边界以[语言参考](/docs/language-reference/)为准。代码注释表示预期结果，不表示每段示例本轮都已实跑。

## 表达式与数据

函数调用写成 `(函数 参数...)`，`;` 开始行注释。数字、字符串、布尔值和关键字可直接求值；符号查找当前环境绑定。

```lisp
(+ 1 2 3)             ;; => 6
"hello"
true
nil
:ready
'(1 2 3)              ;; quote：列表数据，不调用 1
'(+ 1 2)              ;; => (+ 1 2)，不是 3
[1 2 3]               ;; 向量
{:name "Zio" :n 3}    ;; 映射
(get {:n 3} :n)        ;; => 3
```

## 定义、局部绑定与函数

```lisp
(def greeting "hello")
(defn square [x] (* x x))
(let [n 7] (square n)) ;; => 49
((fn [x] (+ x 1)) 4)   ;; => 5
(let [x 2 y (+ x 3)] (* x y)) ;; => 10
(defn collect [x & xs] [x xs])
(collect 1 2 3)       ;; => [1 (2 3)]；rest 是列表
```

顶层 `def` 的绑定保留在当前会话。`let` 与 `let*` **当前均为顺序局部绑定**：后续 initializer 能引用此前绑定；不是两种不同的并行／顺序规则。函数捕获定义处的词法环境。

## 条件与顺序求值

```lisp
(if (> 5 3) :yes :no) ;; => :yes
(cond ((< 5 0) :negative)
      ((= 5 0) :zero)
      (else :positive)) ;; => :positive；每个子句是列表
(do
  (def x 10)
  (+ x 2))            ;; => 12
```

只有 `nil` 与 `false` 为假，`0` 和空字符串都为真。`if` 只执行所选分支；直接写 `(and ...)`／`(or ...)` 会短路，普通函数调用的实参则从左到右求值。`cond` 不使用平铺的 test／expr 对。

多表达式程序按顺序执行，浏览器求值器返回最后一个值；reader 或 evaluator 的错误会显示在输出区域。试着将 `(+ 1 2)` 改成 `(+ 1 missing)`，观察未绑定符号错误。

## 宏、对象与同步队列

当前有 `syntax-rules` 卫生子集和 ZOS 类／通用函数／多分派子集，不宣称完整卫生性或 MOP。`future-call` 立即同步求值并包装结果；`chan` 是同步消息队列，空队列接收或满的有界队列发送可能阻塞当前线程，不能据此推断已有并发调度或取消能力。AST、显式 VM 与 Zio 元循环第三执行面通过行为合同核对；元循环显式入口是 `(zio-meta-eval source name)`，默认执行器不变。L02 首轮便携编译器自举已验收，Stage 1/2/3 制品字节相同；Rust 引导/VM 保留，不代表镜像或完整发行。
